Tips

  • Live shader compiles the script to GLSL and plays it on the GPU, looping; edits show as you type. Frame renders one frame with the original engine on every core: exact, and the one for a weak GPU.
  • Click the picture to pause and play. The slider scrubs; in the shader view it pauses. ⌘/Ctrl+Enter runs, Tab indents.
  • size is the picture, frame and movie size; empty, or ↺, means the script's own fw×fh.
  • oversample keeps the script's 2×2 supersampling; off is four times faster.
  • Render movie… makes an MP4 (H.264) or a zip of PNG frames, drawn by the shader unless you pick the original renderer. Save frame saves the current picture.
  • Save shader (HTML) is a page that plays the loop by itself, images included. Save GLSL is the fragment shader in Shadertoy's dialect: paste it there, with the images in its channels.
  • Images… adds image files a script refers to with image="name"; the examples' images are here already.
  • The script stays in this browser between visits; Save downloads it. The shader is 32-bit float, so very deep fractal zooms need the Frame view.
