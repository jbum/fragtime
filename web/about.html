What this is

Fragtime makes pictures and movies from a formula for every pixel, plus time. Formulas are nodes, wired together on a desk: one warps another, masks a third, plays a fourth at another speed, and a sequence strings them into scenes. The whole patch compiles to a single fragment shader, so it plays live on the GPU while you edit it, and renders movies, stand-alone pages and Shadertoy shaders. The name is a fragment shader over time, and a nod to QTS, the QuickTime Synthesizer, where it comes from.

Pixel Magic began in 1995 as a Photoshop filter and then a Macintosh program: a dialog with a formula for the red, green and blue of each pixel in terms of x, y, the polar coordinates a and d, and t, time, so it could write QuickTime movies as well as stills. It was ported to Windows in 1998–2000, where it gained a preset browser and a flex/bison parser for the language.

QTS ("QuickTime Synthesizer", 2001–2003) was its last form: the same expression language, but the picture is described by a script of nested sequences, each with a start time and duration, which can sample one another, zoom, tile, layer with Photoshop-style blend modes, and sample images. It is the program that made Noise Etude.

In 2026 QTS's renderer was ported from its C++ source to the browser, faithfully enough that the 2001 scripts render as they did (qts.jbum.com keeps that port as it was). A compiler from its scripts to GLSL followed, then Fragtime: the same language and the same shader, with the tree of sequences turned into a graph of nodes. Every QTS script imports as a patch and draws the same pixels; the examples are the QTS archive's.

Related

Syd is the audio counterpart from the same years: a software synthesizer with the same expression language, also running in the browser.
